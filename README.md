# My Finance Dashboard

เว็บแอป HTML + CSS + JavaScript สำหรับจัดการรายรับรายจ่าย มีกราฟแท่ง รายรับเทียบรายจ่าย กราฟวงกลมสัดส่วนรายจ่าย ประวัติตามวันที่ ค้นหา/กรอง/แก้ไข/ลบ และนำเข้า/ส่งออก CSV สำหรับใช้กับ Microsoft Excel

## ทดลองในเครื่อง
แตก ZIP แล้วเปิด `index.html` ด้วย Chrome/Edge โดยต้องเชื่อมอินเทอร์เน็ตเพื่อโหลด Chart.js จาก CDN และแสดงกราฟ

## เผยแพร่ฟรีด้วย GitHub Pages
1. เข้า https://github.com/ และเข้าสู่ระบบ
2. สร้าง Repository ชื่อ `my-finance` เลือก Public
3. อัปโหลด `index.html`, `style.css`, `script.js` แล้ว Commit changes
4. เข้า Settings → Pages
5. Source เลือก `Deploy from a branch`
6. Branch เลือก `main` และ Folder เลือก `/(root)` แล้วกด Save
7. รอเผยแพร่ แล้วกด Visit site

URL จะหน้าตาประมาณ `https://ชื่อบัญชี.github.io/my-finance/`

## ใช้กับ Excel
- ปุ่มส่งออกจะดาวน์โหลด CSV ซึ่งเปิดด้วย Excel ได้
- เพื่อให้อักษรไทยอ่านได้ ไฟล์ส่งออกมี UTF-8 BOM
- หลังแก้ไขใน Excel ให้บันทึกเป็น CSV UTF-8 แล้วใช้ช่องนำเข้า CSV
- รูปแบบคอลัมน์ควรมีหัวตาราง: วันที่, รายการ, ประเภท, หมวดหมู่, จำนวนเงิน, หมายเหตุ
- วันที่ควรเป็น YYYY-MM-DD เช่น 2026-10-17; ประเภทใช้ รายรับ หรือ รายจ่าย

## ข้อจำกัดและความเป็นส่วนตัว
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่ใช่ฐานข้อมูลกลาง ไม่ซิงก์ข้ามอุปกรณ์หรือผู้ใช้ และไม่ได้เชื่อมบัญชีธนาคาร การล้างข้อมูลเบราว์เซอร์อาจทำให้ข้อมูลหาย ควรส่งออก CSV สำรองเป็นระยะ
กราฟใช้ Chart.js จาก CDN จึงต้องมีอินเทอร์เน็ตเพื่อโหลดไลบรารี
